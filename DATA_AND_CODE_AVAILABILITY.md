# Data and code availability

The public reproducibility repository is available at:

https://github.com/ABLE-Du/ETV6-RUNX1-biomarker-reanalysis

The repository contains the harmonized parser, score-development disclosure,
matched-sample C-index code, aggregate non-identifiable result tables, figures,
public-input provenance, and software requirements. Individual-level
single-center clinical data are not publicly released because of privacy and
institutional governance requirements. Third-party public datasets are
available from their original repositories and retain their original terms.

Verified public source identifiers include:

- TARGET-ALL-P2: https://portal.gdc.cancer.gov/projects/TARGET-ALL-P2
- NOPHO targeted sequencing set 1: https://doi.org/10.5281/zenodo.15167703
- NOPHO targeted sequencing set 2: https://doi.org/10.5281/zenodo.15173882
- NOPHO targeted sequencing set 3: https://doi.org/10.5281/zenodo.15174016

The NOPHO identifiers are third-party dataset DOIs and are not the DOI for
this code release.
