## DOI rule for the manuscript

The three NOPHO Zenodo DOIs identify third-party sequencing datasets. They
must not be used as the DOI for this study's code or aggregate result release.
The exact reproducibility release should be cited using version DOI
`10.5281/zenodo.20697294`. The concept DOI `10.5281/zenodo.20697293` resolves
to the evolving repository across future archived versions.
