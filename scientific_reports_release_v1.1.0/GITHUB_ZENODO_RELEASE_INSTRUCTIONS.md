# GitHub and Zenodo release instructions

The public repository URL is:

https://github.com/ABLE-Du/ETV6-RUNX1-biomarker-reanalysis

No repository-specific DOI existed at the time this package was prepared.
Complete the following actions before manuscript submission:

1. Review the release package and confirm that no individual-level
   single-center data are present.
2. Push the package contents to the public GitHub repository.
3. Enable the repository in the Zenodo GitHub integration.
4. Create a GitHub release tagged `v1.0.0` using `RELEASE_NOTES.md`.
5. Confirm that Zenodo archives the release and issues a version DOI and a
   concept DOI.
6. Add the version DOI to the manuscript Data availability and Code
   availability statements, `README.md`, `CITATION.cff`, and `.zenodo.json`.
7. Cite the concept DOI for the evolving repository and the version DOI for
   the exact reproducibility release.

Do not enter a guessed or reserved DOI. Use only identifiers displayed by the
published Zenodo record.
