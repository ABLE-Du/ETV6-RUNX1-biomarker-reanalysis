# STROBE and TRIPOD reporting checklist

| Item | Status | Manuscript action |

## TRIPOD-relevant items

The manuscript is a candidate-score feasibility study, not a validated
clinical prediction model. TRIPOD is applied where relevant.

| Item | Status | Manuscript action |
|---|---|---|
| Model-development objective | Ready | Describe candidate score feasibility, not clinical prediction |
| Data source and participant selection | Ready | Separate derivation and feasibility cohorts |
| Predictor definition | Ready | Unified raw-string parser, variable dictionary, and development disclosure |
| Outcome definition | Ready | Separate MRD time points and EFS |
| Missing data | Ready | Complete-case analysis; report denominators |
| Model specification | Ready | Publish exact points, threshold, and penalizer |
| Internal validation | Ready | 1,000-resample paired bootstrap; conditional on fixed post hoc score |
| Discrimination | Ready | Matched-sample apparent/corrected C-index and paired delta |
| Calibration | Not estimable | Explain inadequate event counts |
| External validation | Not achieved | Explicitly state absence of adequately powered external validation |
| Model availability | Ready | Release code and scorecard |
| Clinical use | Not claimed | Do not recommend treatment decisions based on score |
