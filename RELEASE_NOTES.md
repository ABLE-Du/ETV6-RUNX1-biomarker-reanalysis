# Release v1.0.0

## Purpose

This release freezes the reproducibility materials for the Scientific Reports
submission package.

## Main additions

- Predefined cytogenetic risk-score code and locked scorecard.
- Cohort-specific MRD endpoint definitions.
- Penalized Cox model outputs.
- Five-hundred-resample bootstrap optimism correction.
- Aggregate tables, publication figures, and verified references.
- Frozen statistical analysis plan and SHA-256 manifest.

## Privacy

No individual-level single-center patient data are included.

## Archiving

After publishing this GitHub Release, enable or trigger Zenodo archiving. Zenodo
will issue a version DOI and a concept DOI. Add both identifiers to the
repository README, `CITATION.cff`, manuscript Data availability statement, and
Code availability statement.
