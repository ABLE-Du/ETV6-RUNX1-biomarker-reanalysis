# v2.0.0 — EJH manuscript reproducibility deposit

This major release archives the reproducibility materials for the manuscript
"Cross-cohort convergence of transcriptional states associated with adverse early treatment response in
ETV6::RUNX1-positive childhood acute lymphoblastic leukaemia".

It includes analysis scripts, Python/R environment specifications, non-identifiable derived tables,
figure source data, and submitted journal tables. It excludes copyrighted upstream files, controlled-
access TARGET data, and all institutional row-level records. Author-machine paths were replaced with
environment-variable configuration and the missing shared helper module was restored before release.
