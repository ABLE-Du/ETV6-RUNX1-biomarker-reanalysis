# Data and code availability

The public repository is https://github.com/ABLE-Du/ETV6-RUNX1-biomarker-reanalysis.

This release contains repository-authored scripts and aggregate non-identifiable
outputs. Individual-level single-center data are excluded for privacy and institutional
governance reasons. Public source datasets are not redistributed and remain available
from TARGET-ALL-P2, GEO (GSE181157, GSE184692, GSE227832, GSE228632, GSE87070),
and Oksa/NOPHO Zenodo records 10.5281/zenodo.15167703,
10.5281/zenodo.15173882, and 10.5281/zenodo.15174016.
