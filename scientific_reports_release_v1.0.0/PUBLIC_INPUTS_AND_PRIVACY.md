# Public inputs and privacy boundary

## Public source data

- TARGET acute lymphoblastic leukemia data: National Cancer Institute Genomic
  Data Commons, https://portal.gdc.cancer.gov/projects/TARGET-ALL-P2
- cBioPortal software and study access: https://www.cbioportal.org/
- NOPHO-derived public records, when used by repository analyses, remain
  available from their original Zenodo records and retain their original
  licenses and terms:
  - https://doi.org/10.5281/zenodo.15167703
  - https://doi.org/10.5281/zenodo.15173882
  - https://doi.org/10.5281/zenodo.15174016

Public source data are not redistributed in this release. Users must download
them from the original repositories and comply with the applicable access
conditions.

## Single-center data

Individual-level single-center data are excluded because of ethics, privacy,
and institutional governance restrictions. The release contains only
non-identifiable aggregate tables and figures derived from those records.

## Reproduction boundary

The code documents the complete transformations and statistical models, but
analyses requiring single-center individual-level records cannot be rerun
without an approved data-use agreement. The published aggregate outputs and
SHA-256 manifest permit verification of the released results.
